Control Flow 
-------------
1)Conditional Clause statement.
2)Looping Statements

Conditional Clause statement.
------------------------------
if clause 
------------
syntax:
--------
if cond:
    block of code

True --> executes the block of code 
False --> skip the block

elif
------
syntax:
--------
elif cond:
    block of code 

True --> executes the block of code 
False --> skip the block

else 
-------
syntax:
--------
else:
    block of code
False--> executes the block.
True --> skip

Nested If 
-------------
if cond1:
    if cond2:
        block of code

Loops 
---------
>> it is used to execute a block of code repeatedly.

While
---------
>> conditon based loop. 
syntax:
----------
while codition:
    block of code

>> it executes the block over and over again untill the condition becomes False.

For Loop 
---------
>> Sequence based loop.
syntax:
---------
for varName in Sequence:
    block of code

Range --> range seq.
--------------------
range(len) --> range(5) --> [0,1,2,3,4]
range(start, end) --> range(3,15) --> [3,4,5,6...14]
range(start, end, step) --> range(3,15,1) --> [3,5,7,9,11,13]

Control Statements of Loops 
-------------------------------
break ---> it stops the loop.
continue --> it skips the current iteration.
